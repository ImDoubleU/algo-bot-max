# Скриншоты приложения

Сняты 7 ноября 2026 года через Playwright / Microsoft Edge с текущего интерфейса миниприложения в ветке work/games-prototype. PNG-файлы — прямые снимки страницы или игрового окна, без дорисовки интерфейса.

Использованы локальный стенд app.cli.pizza_preview --games с отдельной демонстрационной базой и локальный HTTP-стенд из tests/test_feedback_workspace_ui.py, обслуживающий настоящий index.html, CSS, JavaScript и каталог материалов курсов. Производственное приложение и базы данных для съёмки не использовались.

Все имена, суммы, группы и заказы относятся к встроенным демонстрационным профилям. QR в семейном кабинете — штатный нерабочий пример. Действующих приглашений, токенов и данных пользователей в изображениях нет. Сбор и игровые награды показаны в изолированном тестовом окружении.

Скриншоты показывают возможности текущей сборки. Их наличие в README не означает, что каждый модуль открыт всем ролям или включён в каждом рабочем окружении.
