# Руководство пользователей Algo MAX

Готовая редактируемая презентация: `Algo_MAX_Руководство_по_ролям.pptx`.

В ней описаны основные сценарии для семи ролей:

- ученик;
- родитель;
- преподаватель;
- куратор;
- администратор;
- директор;
- суперадминистратор.

Презентация использует демонстрационные экраны из каталога `user-guide-assets` и не содержит производственных данных.

Для пересборки после изменения текстов или скриншотов:

```powershell
max_bot_venv\Scripts\python.exe -m pip install python-pptx==1.0.2
max_bot_venv\Scripts\python.exe docs\build_role_guide.py
```

Файл можно редактировать в Microsoft PowerPoint или LibreOffice Impress. Исходный генератор нужен только для массового обновления оформления и повторной сборки.
