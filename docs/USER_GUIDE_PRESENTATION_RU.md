# Подробное руководство пользователей Algo MAX

Готовая редактируемая презентация: `Algo_MAX_Руководство_по_ролям.pptx`.

Редакция 6 содержит 87 слайдов и построена по разделам приложения:

1. Вход, профиль и главная страница.
2. Магазин, корзина и цифровые товары.
3. Заказы: назначение склада, сборка, доставка и выдача.
4. Ученики, начисления и отчет по астрокоинам.
5. Рассылки по группам, площадкам и форматам занятий.
6. Управление филиалом, товарами, складами, импортом и сотрудниками.
7. QR-коды, помощь и ежедневные маршруты ролей.

В презентацию встроено более 50 актуальных экранов desktop и mobile для интерфейса 0.78.1. На каждом практическом слайде элементы интерфейса отмечены номерами, а справа приведены точные действия: куда нажать, что проверить и какой результат ожидать.

Руководство охватывает:

- вход через MAX, проверку профиля, выбор ребенка и рабочего города;
- навигацию на компьютере и телефоне;
- баланс, историю астрокоинов, магазин, корзину и заказы;
- физические и цифровые товары;
- QR-коды и ссылки для детского входа;
- начисления, карточки учеников и выдачу заказов преподавателем;
- отчеты и рассылки куратора;
- назначение склада, сборку, доставку и отмену заказов;
- товары, остатки, цифровые коды, склады и импорт Excel;
- автоматическое распределение импортируемых учеников по существующим городам;
- ручное управление статусом и балансом ученика;
- автоматический подарок 50 AC в день рождения;
- одноразовые ссылки для приглашения сотрудников, роли и персональные настройки уведомлений;
- работу директора с несколькими городами;
- создание партнеров и переключение городов суперадминистратором;
- ежедневные чек-листы и решения частых затруднений.

Дополнительная текстовая версия `INTERACTION_GUIDE_RU.md` содержит 32 практических сценария. Ее удобно использовать для быстрого поиска по названию кнопки или операции без открытия презентации.

Отчет `GUIDE_QA_130_RU.md` фиксирует 130 найденных недочетов предыдущей редакции и способ исправления каждого пункта.

Действия всех семи ролей показаны внутри соответствующих разделов:

- ученик;
- родитель;
- преподаватель;
- куратор;
- администратор;
- директор;
- суперадминистратор.

Презентация использует демонстрационные экраны из каталога `user-guide-assets/visual-v6` и не содержит производственных данных или персональных ссылок.

Для пересборки после изменения текстов или скриншотов:

```powershell
max_bot_venv\Scripts\python.exe -m pip install python-pptx==1.0.2
max_bot_venv\Scripts\python.exe docs\build_role_guide.py
```

PDF для чтения создается общей командой экспорта:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File docs\export_product_materials.ps1 -SkipVideo
```

Файл можно редактировать в Microsoft PowerPoint или LibreOffice Impress. Исходный генератор нужен только для массового обновления оформления и повторной сборки.
