# Подробное руководство пользователей Algo MAX

Основная редактируемая презентация: `Algo_MAX_Руководство_по_ролям.pptx`.

Редакция 7 для интерфейса 0.86.2 содержит 100 слайдов и построена по рабочим разделам:

1. Вход, профиль, объединенные роли и переключение городов.
2. Магазин, сортировка, корзина и цифровые товары.
3. Заказы: склад, сборка, доставка, прием и выдача.
4. Ученики, автоматическая привязка преподавателя, начисления и отчет AC.
5. Рассылки по группам, площадкам и форматам занятий.
6. Сотрудники, роли, ФИО, товары, склады, импорт, связи и история.
7. QR-коды, текущее состояние помощи и ежедневные проверки.

В практических слайдах используется один основной экран и до трех пронумерованных точек нажатия. Справа указаны точное действие и ожидаемый результат. Desktop и mobile показаны отдельно там, где меняется навигация.

Отдельные материалы:

- `INTERACTION_GUIDE_RU.md` — 42 полные процедуры с условиями, путем, кнопками, проверкой, исправлением и ограничениями.
- `SCREENSHOT_REGISTER_RU.md` — реестр экранов, роли, состояния и места использования.
- `VIDEO_SERIES_RU.md` — короткое видео, обзор и шесть ролевых курсов.
- `QA_REPORT_RU.md` — фактическая, практическая и визуальная проверки.

Публичные роли: ученик, родитель, преподаватель, куратор, администратор и директор. Служебные роли в материалах не показываются.

Для пересборки:

```powershell
max_bot_venv\Scripts\python.exe docs\build_role_guide.py
powershell.exe -NoProfile -ExecutionPolicy Bypass -File docs\export_product_materials.ps1 -SkipVideo
```

Презентация использует безопасные локальные данные и не содержит рабочих приглашений, токенов или персональных ссылок.
