# Материалы по продукту Algo MAX

Комплект разделен по назначению, чтобы подробная инструкция не перегружала демонстрацию продукта.

## Полное руководство

- Редактируемая версия: `Algo_MAX_Руководство_по_ролям.pptx`.
- PDF для чтения: `..\output\pdf\Algo_MAX_Полное_руководство.pdf`.
- Объем: 85 слайдов, более 50 экранов приложения с указателями.
- Назначение: обучение пользователей и пошаговая проверка рабочих сценариев.

Руководство собрано по разделам приложения: вход и профиль, магазин, заказы, ученики и астрокоины, рассылки, управление филиалом, QR-коды и помощь. Действия ученика, родителя, преподавателя, куратора, администратора и директора показаны на desktop- и mobile-экранах. Пронумерованные указатели объясняют конкретные кнопки, поля, ожидаемый результат и контроль после операции.

- Текстовый каталог действий: `INTERACTION_GUIDE_RU.md`.
- Объем каталога: 32 сценария от входа до управления городами.
- Реестр проверки: `GUIDE_QA_130_RU.md`, 130 закрытых замечаний.

## Презентация продукта

- Редактируемая версия: `Algo_MAX_Презентация_продукта.pptx`.
- PDF для показа без PowerPoint: `..\output\pdf\Algo_MAX_Презентация_продукта.pdf`.
- Объем: 35 слайдов.
- Назначение: демонстрация директору, сотрудникам школы или новому партнеру.

Презентация показывает действующий функционал без производственных данных, а затем проводит пользователя по 15 основным операциям с точными названиями кнопок.

## Серия видео

- Индекс серии: `VIDEO_SERIES_RU.md`.
- Исходники презентаций и тексты диктора: `video-series`.
- Готовые MP4: `..\output\video-series`.
- Машиночитаемый аудит: `..\output\video-series\strict-triple-audit.json`.
- Итоговый отчет: `VIDEO_TRIPLE_REVIEW_RU.md`.
- Формат: 1920×1080, CFR 25 кадров/с, H.264 High, AAC mono 48 кГц, русская озвучка Piper `ru_RU-dmitri-medium`.

Серия состоит из короткого ознакомительного ролика, подробного обзора продукта и шести отдельных видео по пользовательским ролям: ученик, родитель, преподаватель, куратор, администратор и директор. Короткий ролик предназначен для первого знакомства, подробный — для демонстрации сквозной системы, ролевые — для обучения конкретным кнопкам и ограничениям.

Пересборка и проверка всей серии:

```powershell
max_bot_venv\Scripts\python.exe docs\build_video_series.py
powershell.exe -NoProfile -ExecutionPolicy Bypass -File docs\export_video_series.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File docs\build_video_contact_sheets.ps1
max_bot_venv\Scripts\python.exe docs\audit_video_series_strict.py
```

## Архивное объединенное видео

- Готовый файл: `..\output\video\Algo_MAX_Обзор_продукта.mp4`.
- Сценарий озвучки: `VIDEO_SCRIPT_RU.md`.
- Длительность последней сборки: 18 минут 58 секунд.
- Размер последней сборки: около 107 МБ.
- Формат: 1280×720, 24 кадра/с, русская нейросетевая озвучка Piper `ru_RU-dmitri-medium`.
- Настройка и повторная сборка озвучки: `TTS_SETUP_RU.md`.

Видео сочетает обзор продукта и практическое обучение. Оно сохранено как архивная объединенная версия; для показа и обучения используйте новую серию.

## Пересборка

Сначала обновить обе презентации и сценарий:

```powershell
max_bot_venv\Scripts\python.exe docs\build_role_guide.py
max_bot_venv\Scripts\python.exe docs\build_product_presentation.py
```

Затем создать PDF и MP4 через Microsoft PowerPoint и локальный нейросетевой голос Piper:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File docs\export_product_materials.ps1
```

Только PDF, без повторного рендера видео:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File docs\export_product_materials.ps1 -SkipVideo
```

Готовые PDF и MP4 находятся в `output` и намеренно не добавляются в Git: это воспроизводимые крупные файлы. Исходники презентаций, сценарий и генераторы хранятся в репозитории.
