# Живая озвучка видео Algo MAX

Основная серия подготовлена для самостоятельной озвучки. MP4 не содержит сгенерированного голоса.

## Что открыть перед записью

1. Выберите нужный файл `docs\video-series\*.script.md`.
2. Откройте соответствующий MP4 рядом со сценарием.
3. Для контроля времени используйте колонку «Таймкод».
4. Читайте только колонку «Текст диктора». Действия курсора и экранные подписи служат монтажным планом.

## Параметры записи

- Темп: 125–140 слов в минуту.
- Формат исходника: WAV, 48 кГц, 24 бит; один микрофонный канал.
- Расстояние до микрофона: 12–18 см, положение не менять между дублями.
- Пиковый уровень при записи: примерно от -12 до -6 dBFS.
- Пауза между смысловыми блоками: около одной секунды.
- Названия кнопок произносить точно как на экране.

Записывайте каждый ролик отдельным файлом. Ошибочную фразу повторяйте с начала предложения и оставляйте короткую паузу перед дублем: так ее проще найти на монтаже.

## Контроль перед монтажом

1. Голос разборчив без шумоподавления, которое обрезает окончания слов.
2. Длительность фразы помещается в таймкод кадра.
3. В тексте нет добавленных обещаний или функций, которых нет на экране.
4. После склейки SRT совпадает с произнесенными фразами.
5. Итоговый голос нормализован примерно до -16 LUFS, без клиппинга.

Дополнительный плагин не требуется. Для записи подойдет любой редактор, который сохраняет WAV без автоматических эффектов.
