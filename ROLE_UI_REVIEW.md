# Проверка интерфейса по ролям

Версия проверки: `0.75.0`. Данные не очищаются до отдельной команды владельца проекта.

## Все роли

- [x] `UI-COMMON-001` — удален повторяющийся блок «Сегодня» с названием главной страницы; контекст роли остается в содержательном первом блоке.

## Ученик

- [x] `UI-STUDENT-001` — верхняя панель собрана в единый блок: профиль, компактный баланс с обновлением и корзина.
- [x] `UI-STUDENT-002` — завершенные заказы для ученика и родителя называются «Получены».
- [x] `UI-STUDENT-003` — приветствие учитывает время суток и показывает имя ученика.

## Родитель

- [x] `UI-PARENT-001` — рядом с QR-кодом ребенка есть копирование точной ссылки.
- [x] `UI-PARENT-002` — внутренние пояснения про сводку, комплектацию и распределение скрыты или заменены понятным текстом.
- [x] `UI-PARENT-003` — убран дублирующий выпадающий фильтр заказов; оставлены вкладки состояний и поиск.

## Преподаватель

- [x] `UI-TEACHER-001` — отмена заказа недоступна ученику, родителю, преподавателю и куратору; разрешена администратору, директору и суперадминистратору.
- [x] `UI-TEACHER-002` — повтор подписи «Рабочий день» внутри приветственного блока убран.

## Куратор

- [x] `UI-CURATOR-001` — у текста рассылки добавлен выбор эмодзи со вставкой в позицию курсора.

## Директор

- [x] `UI-DIRECTOR-001` — показатели сводки считают разные сущности: незавершенные заказы, ожидающие выдачи и физические единицы в резерве.
- [x] `UI-DIRECTOR-002` — вкладка amoCRM и связанные пользовательские элементы убраны; файловый импорт называется «Импорт данных», исторические записи в базе сохранены.
- [x] `UI-DIRECTOR-003` — директор может отзывать и восстанавливать существующих администраторов своего города, но не управлять директорами и суперадминистраторами.

## Контроль перед выпуском

- [x] Синтаксис клиентских JavaScript-файлов.
- [x] Точечные сценарии API ролей, заказов и сводки.
- [x] Desktop `1440x900` по всем ролям.
- [x] Mobile `390x844` по всем ролям.
- [x] Публикация на VPS и проверка HTTPS.
